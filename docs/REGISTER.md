# Object register (merged from 10 independent survey lists + automatic stud detection)

Method: **conform** = quad cage subdivided and pulled onto the sculpt; **model** = built clean from
parameters, placed by measurement; **hybrid** = modelled shape seated on / fitted to the sculpt;
**trim** = section swept along another object's edge; **ask** = needs the user's decision.
Counts marked ~ were disputed between surveyors; the build uses the detected positions in
`survey/bumps.json` where they exist. Group = who builds it (lead or builder A-F).
